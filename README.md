## PROPOSITO/OBJETIVO
El proposito de nuestra aplicación es poder brindar una herramienta de apoyo psicopedagogíco en la etapa de nivel incial de lectoescritura, mediante  la técnica del puntillismo (unir puntos para formar letras y trazos). Nuestro objetivo es poder llegar a ser de mucha ayuda tanto a docentes como estudiantes.
## Objetivos:
* Ofrecer un método de aprendizaje seguro e interactivo para acompañar el desarrollo del nivel inicial.

* Reducir la frustracion y la ansiedad que génera la escritura tradicional.

* Estimular la motricidad fina mediante actividades de trazado y arrastree.

* Mejorar la caligrafía 

* Favorecer la percepción audio-visual y el roconocimiento de las palabras

## Destinatarios:

La aplicación esta destinada al publico en general, que tenga la necesidad de poder aprender de una forma rapida y sencilla de aprender a escribir.
